NEBULAR

Catching planets across the cosmos.

How It Works

When an exoplanet passes in front of its host star, it blocks a tiny fraction of the star's light. Nebular processes light curve time-series data, removes stellar variability, and uses Box-fitting Least Squares (BLS) algorithms to detect periodic transit dips.

Data Attribution

All photometric observations are retrieved directly from the public NASA Kepler Mission archive using the Lightkurve python package.
